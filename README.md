# Customer Segmentation using Self-Organizing Maps (SOM)

## Overview
This project applies a Self-Organizing Map (SOM) to segment 
mall customers into behavioural clusters based on Age, 
Annual Income, and Spending Score.

## Dataset
Mall Customers Dataset - 200 customers (from Kaggle)

## Libraries Used
- minisom
- scikit-learn
- pandas
- matplotlib

## How to Run
1. Clone this repository
2. Install dependencies: pip install minisom scikit-learn pandas matplotlib
3. Open som.ipynb in Jupyter Notebook or Google Colab
4. Run all cells sequentially

## Results
4 customer clusters identified:
- Cluster A: Middle-aged Moderate Spenders
- Cluster B: Young High-Value Customers
- Cluster C: Budget-Conscious Customers
- Cluster D: Wealthy Conservative Spenders
